# 一对一协议下的位姿图边质量实验

输入为 TUM fr1/xyz 的 790 帧一对一关联，选出 125 个关键帧。顺序边和回环边都记录共享最终变换质量；真值只在优化结束后计算轨迹指标和候选标签。

| 轨迹 | ATE(m) | RPE Δ1(m/°) |
| --- | ---: | ---: |
| 优化前 | 0.044338 | 0.014733/1.246 |
| 通过门限的位姿图 | 0.029692 | 0.014641/1.236 |
| 强制加入 1 条错误边 | 0.464398 | 0.038497/1.710 |

顺序边共 124 条：84 条通过共享质量门限；40 条没有把低质量 ICP 当成确定边，而是回退到已评测的逐帧里程计相对位姿。

正式回环候选 30 条：接受正确/接受错误/拒绝正确/拒绝错误 = 22/1/7/0。误接受 1，误拒绝 7。

另测试 10 个不入图的 hard negative，其中 10 个被相同门限拒绝，事后真值标为错误的有 9 个。强制错误边实验明确绕过生产门限，仅用于量化错误约束对优化的影响。

逐边指标、拒绝原因、轨迹和 Open3D 位姿图 JSON 均保存在本目录；大点云地图留在本地 artifacts，不提交 Git。
